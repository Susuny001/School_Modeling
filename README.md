## 【每轮生成内容】（不是交付）

每轮稳定工作版本实际生成并核对：

1. 同版统一 `.glb`；
2. 同版可编辑原生 `.blend`；
3. 同版实际 `.fbx`，这是用户的永久新增要求；
4. 同版统一 HTML 入口，嵌入的模型与本版 GLB 相同；
5. 由该版实际模型渲染的演示图，包含能检视本次改动的角度。

不能只改扩展名、存空壳、留旧 FBX，也不能只有局部样件而称统一模型已输出。构造失败的内部试验必须明确拒绝，不得冒充稳定版本。

生成的fbx必须满足**可编辑性**：

- 窗户、各类门、栏段、树、墙、桌、椅、书、书箱等实际单件应能单独选择与调整。
- 原生和 FBX 保留建筑、楼层、教室等合理层级与轴心。
- 玻璃、窗框、墙洞和内部空间是真实几何和材质，不靠照片伪装。
- 用户希望能直接用的 FBX Prefab 包；如实际生成 `.unitypackage`，须是本版模型、实际导入并检查，不能拿历史包冒新包。
