Campus V113 — 直接打开版

【打开】
1. 双击：打开地图_V113.html
2. 不需要联网、不需要本地服务器、不需要安装 three.js。GLB 已内置在 HTML 中。
3. 页面加载完成后，点击画面任意位置即可进入鼠标视角。

【主视角操作】
- 点击画面任意位置：捕获鼠标并操控视角。
- Alt 或 ESC：释放鼠标。释放后视角保持不变，不弹出恢复窗口。
- 鼠标释放状态下：W/A/S/D、Space、Shift 仍可继续移动；可以直接点击“设置”。
- W / A / S / D：前 / 左 / 后 / 右
- Space：上升
- 左 Shift：下降

【设置】
设置面板可调整：
- 鼠标灵敏度
- 移动速度
- 视野 FOV
- 六个移动键位
- 传送到指定坐标 (X,Y,Z)，传送时保持当前水平角 / 俯仰角
- 对照视角 1–6：一键跳到用户给定的六组坐标与水平/俯仰角
设置保存在当前浏览器 localStorage；若 file:// 环境禁用存储则自动使用默认值。

【坐标与视角】
左上 HUD 持续显示 X / Y / Z、水平角、俯仰角，均精确到 0.1。

【V113 本轮针对用户反馈的改动】
- 删除旗杆后方建筑的连续弧形/浅折线方案，改成一整条真正笔直的主楼体；正面、背面均增加实体窗格、分缝、端部直板与楼梯玻璃塔。
- 按最新对照图改为灰色板材/玻璃组合，中央双层入口、柱廊、玻璃山墙和两侧竖向玻璃楼梯塔均为实体几何。
- 旗杆增加红旗实体网格；旗杆改用独立高金属度、低粗糙度材质组；HTML 查看器也实际读取 metallic/roughness 并计算镜面高光，不再把旗杆材质参数丢掉。
- 缩小主礼仪广场图案尺度，使建筑和旗杆在给定坐标下的相对视场更接近对照图。
- 科学楼/球顶楼重新按对照图改为直线长楼；中央车行门洞改成真正镂空的分体结构，不是画在实体墙上的假门洞；球顶缩回屋顶尺度，增加中央玻璃山墙、四柱架空门厅、红色层间线、屋顶设备。
- 将原先与科学楼球顶冲突的第二礼仪圆场移开。
- 补充旗杆广场东侧大树框景；补充航拍中灰楼背面窗；在对照 4 对应宿舍/教学楼上增加实体红色竖幅与金色立体笔画。
- 按对照 5/6 增加科学楼东侧停车场、车辆、树列、主入口轴线和实体校门；按航拍补充远景城市体块与几何山脊。
- 默认 FOV 调整为 60°；设置中仍可 35–80° 调整。
- 继续保持禁止贴图：GLB 中 textures/images/samplers/TEXCOORD/COLOR 属性均为 0；没有把视频帧、照片裁切或像素采样作为贴图投射。
